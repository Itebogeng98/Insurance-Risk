# Assignment 4 Preparation Pack

This pack documents the existing Integrated Life Insurance Risk Assessment System.
It does not substitute another project or invent a deployed AI service.

## Deliverables

- `ISJ107V_Assignment 4_StudentNumber.pdf`: draft searchable report; planned eleven body pages, plus cover, references and declaration appendix.
- `Assignment4_Presentation_Slides.pdf`: seven slides timed for five minutes.
- `presentation_notes.md`: spoken script, ten-minute demonstration, fictional manual inputs, fallback plan and technical questions.
- `Assignment4_Report_Source.md`: editable report content generated by the builder.
- `uml/*.puml`: five editable PlantUML diagrams, with corresponding PNG exports.
- `build_assignment4.py`: regenerates report and slides from the content and existing evaluation evidence.

No application tests, training, database changes or credential creation were performed
to produce this pack. Diagram rendering and PDF generation are document operations.
